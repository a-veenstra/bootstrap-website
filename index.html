Stop writing media queries from scratch. Use Bootstrap's grid system to create layouts that adapt perfectly to phones, tablets and desktops.

Grid System

Our 12-column grid system allows you to build complex layouts with ease.

Mobile First

Styles are optimized for mobile devices first, then scaled up for larger screens.

Utility classes

Modify properties like margin, padding, and color directly in your HTML.

Code Less, Do More

Bootstrap utilizes a handful of important global styles and settings that you'll need to be aware of when using it, all of which are exclusively geared towards the normalization of cross browser styles.
